# Telegram Bot: Мониторинг и Расписание

## Как запустить:
1. Распакуйте этот архив в отдельную папку.
2. Переименуйте файл `.env.example` в `.env`.
3. Откройте `.env` и впишите свои ключи, токены и ID администратора, а также ссылку на GitHub.
4. Установите библиотеки: `pip install -r requirements.txt`
5. Запустите бота командой: `python main.py`

При первом запуске скрипт попросит ввести номер телефона и код подтверждения от Telegram для авторизации аккаунта, который будет читать группы (Userbot).
